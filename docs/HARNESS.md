# 教育 Agent Harness：实现、约束与验证

## 目的与核心结论

本系统要解决的具体问题是：将学生的自然语言回答转成有原话依据、帮助条件、阶段和版本的理解证据，并检验独立新任务中的表现。模型负责受限的判断与选题；harness 是模型外侧负责输入、工具、状态、上下文、预算、记录和恢复的运行设施。

![运行机制](harness.svg)

这张图从左向右读：学生输入先进入会话边界，评估员提交证据，规划员从允许的任务里选题；宿主验证后保存并暂停。下方三条输出分别是教学与复核、不可被摘要替代的原始记录、独立标注及研究数据。它们不能相互充当成功证明。

本项目是两个顺序执行、消息隔离的模型角色，加上受控教学流程。无密钥时使用显式标记的规则路径，不称为模型自治。没有任意 Shell、文件执行、网络搜索工具、自治 Agent 团队或外部 MCP 接口。

## 旧瓶颈与本轮改动

旧版只有三个较粗能力和固定追问，所有任务提示等级均为0，标注者会看到自动分数。一个知识点可能把早停与测试泄漏混在一起；学生得到方向性提示后答对也可能被当成独立表现。单次HTTP调用缺少跨重试的运行检查点。

当前改成五能力、35道审核示范任务：A诊断15道，B即时复测10道，C延时检查10道。五能力分别为泛化差距、复杂度与噪声、早停、正则化、数据划分。诊断最多10轮，不能因此宣称能确认所有能力；证据不足应保留未知。

## 角色与工具权限

| 角色 | 可调用工具 | 不能做什么 |
| --- | --- | --- |
| evaluator | `load_skill(evidence-assessment)`、`record_assessment` | 不能改掌握分数、切换任务、执行外部操作 |
| planner | `load_skill(adaptive-questioning)`、`choose_question` | 不能越过覆盖、阶段或十轮预算；不能从候选外出题 |
| tutor流程 | 宿主读取整理好的讲解和三级支持 | 当前不另起教师模型循环，不生成未审核参考答案 |

技能在对应角色运行时读取，不将所有教学材料塞进一个共享系统提示。每个模型角色拥有独立messages；历史输入和学生回答作为数据序列化，不作为权限来源。模型自称教师、管理员或要求“忽略规则”不会增加工具权限。

工具定义、允许名称、参数验证和处理器在宿主注册。每次模型响应只允许一个工具调用；结果仍需语义与阶段校验。终止工具提交后立即退出该角色循环。`load_skill`是只读工具，可在下一步模型调用中继续执行；未在有限步骤内提交终止动作会停止运行。

## 评估协议

`record_assessment`要求 correctness、evidenceQuotes、demonstrated、missing、misconceptions、rationale。正确性取correct/partial/wrong/insufficient。每条引用必须逐字存在于当前回答；非弃判结果必须有引用。correct不能同时出现缺失项或明确误解，也必须有已体现能力。

这些校验只能拒绝结构错误、引用捏造和部分明显矛盾，不能证明语义判断正确。真实否定、反讽、抄题或隐藏误解仍需教师验证。原话匹配不等同于事实核查，更不等同于真实掌握。

离线规则用于无密钥体验，不理解语言语义；每条结果保留offline-rules标记，不能自动升级成人工标签。

## 规划与阶段边界

固定策略依次执行五道完整解释，再执行五道迁移。自适应策略先覆盖五项能力，再依据最近误解、缺失依据及已有任务选择补充追问或迁移。真实模型通过choose_question选择；宿主只允许eligibleDiagnostic返回的候选。固定策略不调用模型规划员，评估器仍可相同，方便研究比较。

追问当前是审核题库中的任务，不是任意生成的新题。不同策略的问题本来可能不同，因此静态记录上的分类一致率比较，不能直接证明自适应追问导致学习进步。

诊断结束时保存diagnosis初始快照。教学后只用B题，延时只用C题；每套任务ID不重复。延时在最近一次即时复测完成后默认24小时到期，需要学习者回来主动开始；没有后台提醒或自动发消息。延时批次开始后该会话不再新增教学，避免混淆学习时间与复用已答C题。

## 支持条件和门槛

每轮支持记录level、answerSeen、实际hints及呈现时间。1级给方向，2级引导关键比较，3级提供别例示范。独立复测和延时检查禁止领取这些提示。学生请求帮助后，原题后续正确仍是受助表现；不能通过隐藏提示重新登记为独立。

本阶段证据分只平均本阶段可评分回答：correct=1、partial=0.5、wrong=0，insufficient不参与。它是描述性证据分，不是概率。诊断、复测、延时不通过任意加权合成一个伪精确掌握率。

“本轮已验证”要求同阶段完整解释和迁移均独立正确，短追问不能替代完整解释。最新错误或未知会撤回旧结论，旧证据仍保留。延时通过也只支持本次任务条件下的保持线索，不推出长期稳定能力。

## 一次作答的持久状态

1. 校验taskId、回答长度、requestId与输入hash，领取会话文件锁。
2. 检查该requestId是否已完成；相同输入直接返回当前会话，不再调用模型。相同编号但不同输入返回409。
3. 保存run_started和原始草稿、支持快照、预算及稳定runId。
4. evaluator运行并保存assessment检查点。此时尚未接受学生作答，也未推进题目。
5. planner选择合法下题并保存nextTaskId检查点；复测按固定隔离任务推进。
6. 在独立副本上追加turn、更新阶段与requests，检查截止时间后原子提交answer_assessed。
7. 暂停等待学习者。失败记录run_failed并保留原题、原答复与检查点；重试不重做已完成评估。

预算/上下文耗尽标为blocked，不能无限重试；可导出记录或新建会话。模型暂不可用、格式错误或超时标为retryable，仍受同一个run预算约束。新建会话不是多用户计费限额机制。

## 日志与并发范围

每个UUID会话一个JSONL文件。历史事件逻辑上追加，物理上对小会话重写完整日志到同目录临时文件，fsync后rename，避免一行只写一半。projection是恢复视图，answer_assessed才是被接受的学习证据。每行带序号、上一行hash和当前hash，可发现损坏和部分编辑；本地有写权限者可以重算整条链，因此它不是防恶意篡改的认证证明。

每个会话使用wx文件锁，不是仅进程内Map；相同数据目录里的活跃写请求会被拒绝并发。它是同机文件系统协议，不是分布式数据库或网络文件系统租约。默认一个常驻Node服务，未实现用户身份、访问控制、集群调度。

HTTP请求不会自动删除死进程留下的锁，避免两个恢复者误删新锁的ABA竞争。发生进程硬退出时，先停止所有共享此目录的服务，再执行：

```bash
npm run recover -- --offline
```

恢复脚本只删除确认进程已停止的`.jsonl.lock`，不修改证据或分数。然后启动服务，用原requestId重试；GET提供pendingDraft以便浏览器草稿丢失时恢复。

## 截止时间、预算与钩子

默认每角色最多8步、每次作答最多6次模型调用、单次输出最多1200tokens、模型等待30秒、整轮90秒。工具等待使用整轮剩余时间。before_model、after_model、before_tool、after_tool、checkpoint、run_failed、paused等结构化事件同时进入轨迹与持久日志；不记录模型隐藏思维链。

每次模型调用前以UTF-8字节估算输入并预留最大输出，超过会话预算则拒绝调用。得到服务商有效usage后用已报告量结算；未知或失败请求保守保留预留量。reportedTokens与估算量分开显示。该方案不是准确tokenizer、价格控制或真实信用额度，更不能保证服务商计费小于某金额。

超时信号传给fetch和工具，等待本身有界；结果返回后和终止checkpoint前再次检查，最终rename前也检查。取消不能杀死任意不合作的JavaScript；当前允许工具只读技能或返回结构化数据，写入由宿主集中执行，迟到结果没有独立写权限。

## 上下文与原话保全

模型读取最近最多四轮原话，旧轮次压成含turnId、知识点、阶段、支持条件、旧判分和来源指针的账本。上下文超限继续省略近期/旧记录并登记omittedTurnIds。每份模型上下文带digest和字符数。完整原话始终在服务端日志，摘要不覆盖它。

这不是语义无损压缩，也没有模型自动总结后写回学习者事实；复杂远距离指代可能因此无法判断，应输出insufficient。当前模型总输入还需满足maxContextChars，系统提示与工具定义也计入限制。

## 独立标注与训练数据

`GET .../review`只提供任务、学生回答、帮助条件和评分标准，不含模型判分或分数。`?review=<UUID>`直接进入此接口，不先读取自动结果。提交blind:true只返回保存确认，仍停留在独立视图。

这不是双盲实验或标注者身份认证。曾看过自动结果的人不能通过切换页面变成从未看过；研究时应让另一标注者直接打开专用链接。匿名学习者代号用来划分数据，不应填写个人敏感资料。

逐轮标签与知识点标签分开保存为事件。多人分歧不能悄悄取最后一个人的意见当gold；训练导出只纳入满足约定的人工标签，并按学习者（缺省按会话）分组切分，避免同学生跨训练测试集。具体以评测和导出脚本输出的manifest为准。

当前人工界面提供correctness/evidenceQuote/note，因此SFT导出只监督这三个字段。它不是完整在线工具调用训练集；在线record_assessment还要求其他证据字段与原生tool_calls。需要补充标注或适配验证后才能部署，不能将自动demonstrated/missing/misconceptions当成人工监督拼入目标。

## 验证与未完成事项

自动测试检查课程边界、帮助条件、模型工具协议、引用、权限、超时、预算、幂等、原子写失败、日志降级、盲接口和阶段流程。模拟模型响应只证明协议和失败路径可控；没有密钥的环境不报告真实模型调用已通过。

仍需要真实学生的独立标注、随机或匹配对照设计、留出新任务与延时结果，才能检验判断和教学效果。当前没有训练专门权重、标定BKT/IRT、部署多用户服务、集成OpenMAIC代码、复刻Claude Code核心源码或生成课程视频。
