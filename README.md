# MasteryMap 自适应学习地图 Demo

这是一个“宏观筛查 → 微观下钻 → 个性化学习地图”的可运行 Demo。

## 核心逻辑

1. 先将领域拆成 5–7 个宏观主干。
2. 每个主干先问一道高区分度问题。
3. 答错，或答对但信心不足时，进入该主干的子知识点继续提问。
4. 正确性和信心共同形成掌握度证据。
5. 结果页区分“已掌握、待巩固、薄弱、未深入”，避免把没问过的内容误判为已掌握。
6. 学习路径优先安排基础断点，再安排方法选择和迁移练习。

内置“传统机器学习”完整离线示例。其他主题可通过 DeepSeek 动态生成知识树和问题。

## 运行

需要 Node.js 18 或更高版本。

```bash
npm start
```

浏览器打开：`http://127.0.0.1:4173`

## 启用 DeepSeek

复制 `.env.example` 为 `.env`，在本机填入：

```text
DEEPSEEK_API_KEY=你的密钥
PORT=4173
```

密钥只由本地服务端读取，不会发送到浏览器。不要把 `.env` 提交到 Git 或发给其他人。

## 学习闭环（新增）

诊断后点击路径的“开始学习”或地图的“学习 / 复测”。系统把当前知识点与相关答题证据发送给 DeepSeek，生成可直接阅读的文字微课程：概念讲解、逐步例题、自练题及解析、两道新情境复测题。讲义可下载为 TXT。

阅读不会提高分数。复测两题全对，本轮证据分更新到 85%；一题对为 60%，全错为 30%。地图与推荐路径随之更新。未通过时，可选择重新讲解并换题，本次错因会加入生成上下文。同一套题提交后锁定，避免重复作答刷分。

结果、课程与最新复测记录保存在当前浏览器 localStorage，刷新后可“继续上次学习”。这是即时学习闭环；尚不包含定时复习或长期遗忘模型。当前路径按薄弱程度和重要性排序，并未建立严格的先修依赖图。文字微课程需联网调用 DeepSeek；未接入外部视频课程检索。

- 掌握度是可解释的启发式分数，用于展示完整产品逻辑，不是经过标定的正式知识追踪模型。
- 下一步可以换成 BKT、IRT 或 DKT，并记录跨轮次学习证据。
- 动态生成的问题正式使用前还需要题目质量审核、难度标定和知识点覆盖检查。
